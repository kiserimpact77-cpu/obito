أدخل GitHub Access Token للمتابعة

التوكن بيتخزن في متصفحك فقط (localStorage) ولا يُرسل لأي مكان غير GitHub مباشرة. يمكنك توليده من: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens، وحدد صلاحية "Contents: Read and write" على ريبو obito فقط.
